# Retro Binary Clock Display

## 概要
現在時刻（HH:MM:SS）の各桁を4ビットのLEDグリッドで表示するレトロなバイナリ時計。各LEDをクリックして点灯/消灯できるデモモード付き。

## 機能
- リアルタイムのバイナリ時計表示（1秒更新）
- 6列×4行のLEDグリッド（HH MM SS各2列）
- 各LED（ビット）クリックで点灯/消灯（デモモード）
- 十進数時刻の同時表示
- バイナリの読み方ガイド
- デモモード/ライブモード切替

## 使い方
ライブモードでは現在時刻が自動表示されます。LEDをクリックするとデモモードに切替わり、自由に点灯/消灯できます。「Live Time」ボタンで現在時刻に戻ります。各列は上から8-4-2-1の重みで、点灯しているLEDの合計が各桁の値です。
