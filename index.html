How to Read Binary Clock

• Each column represents a digit of HH:MM:SS

• Read each column from top (MSB=8) to bottom (LSB=1): 8-4-2-1

• Lit LED = 1, Dark LED = 0. Sum the lit LEDs for each digit

• Example: top two LEDs lit in a column = 8+4 = 12 (i.e., digit is 2, tens place)
